MS in Applied AI, University of San Diego. AAI-520: NLP and Generative AI, final project.

Team: Data lead, NLP lead, Agent lead (Nicole Rowley), Evaluation lead.

EquityAgent researches a stock ticker end to end: it plans the research, calls market, macro, news and SEC-filing tools, runs a five-step prompt chain over the news, routes each task to a specialist, writes a brief, grades and revises it, reflects on the run, and stores lessons that change the next run's plan. Demo tickers: NVDA, JPM, XOM.

A2. Kaggle news EDA

The labeled dataset is Kaggle: Sentiment Analysis for Financial News (the Financial PhraseBank). The cell below downloads it once with the Kaggle API; add KAGGLE_USERNAME and KAGGLE_KEY to Colab Secrets, or drop all-data.csv into data/kaggle/ by hand.

The same sentences ship with the original release in data/kaggle/FinancialPhraseBank/ (Malo et al., 2014). Each sentence has 5 to 8 annotations, and the release groups sentences by how strongly the annotators agreed (100%, over 75%, over 66%, over 50%). The classifier diagnostics below use those groups to read the classifier's errors.

Cleaning. Rows are compared on a normalized key (case-folded, punctuation removed), which finds near-duplicates that an exact match misses (Jurafsky & Martin, 2026, Sections 2.4 and 2.6). A sentence that appears with two different labels has no single gold label, so it is dropped. The normalized key is used only for matching; the classifier sees the original text, because case carries sentiment signal (Section 2.6).

A3. Classifier evaluation: keyword baseline vs LLM

The live news chain uses a longer prompt that also asks for relevance, but the Kaggle headlines have no target company, so that instruction would only add noise here. Because LLM output varies between runs (about 2 points of accuracy at n = 300), the score is the mean of three runs.

A4. Classifier diagnostics: supervised baseline, few-shot prompts, agreement

Three checks on the zero-shot LLM classifier above:

  1. A supervised baseline. A pretrained model can be applied to a task by prompting it or by training on labeled data (Jurafsky & Martin, 2026, Section 9.4). TF-IDF with logistic regression, trained on the same train split, stands in for the second, so the LLM is compared with a model that learned from these labels and not only with keywords.
  2. Few-shot prompting. Two demonstrations per label are added to the prompt, drawn from the train split, as Brown et al. (2020, Section 2.4) draw conditioning examples from the training set and never from the test set. Demonstrations come from sentences every annotator agreed on, and K is fixed in advance rather than tuned on the test set. The sentiment definition in the prompt now restates the PhraseBank annotation guideline: judge only what the sentence states, from an investor's view of the stock price (Malo et al., 2014).
  3. Majority vote across runs. The three runs per prompt are combined by majority vote, the self-consistency idea of keeping the answer most samples agree on (Wang et al., 2023). It reuses the runs already made, so it adds no API calls.

Finally, accuracy is broken down by annotator agreement. If the model is far more accurate where every annotator agreed, many remaining "errors" are sentences that people also labeled differently.

Reading the results (run of October 18, 2026). The zero-shot LLM reached 0.834 accuracy and 0.838 macro-F1 (mean of three runs), against 0.793 and 0.771 for TF-IDF with logistic regression and 0.687 and 0.575 for the keyword baseline. Neutral recall rose from 0.72 in the October 14 run to 0.85. That run used the earlier prompt and a test sample drawn before the extra de-duplication, so the gain combines the guideline-based sentiment definition with the cleaning. Few-shot demonstrations did not help (0.827 and 0.833): once the label definition is explicit, two examples per class add little. The majority vote raised the zero-shot scores slightly, to 0.840 and 0.843.

Every classifier loses accuracy as annotator agreement falls. The zero-shot LLM is right on 95% of the sentences every annotator agreed on but on 47% of those where only 50-65% agreed, and TF-IDF and few-shot fall to similar levels there. The lowest band is a ceiling set by the labels, not only by the model.

One caveat: the Financial PhraseBank has been public since 2014, so the LLM may have seen these sentences during pre-training. Brown et al. (2020, Section 4) show that such test-set contamination can inflate benchmark scores, so the LLM's numbers may be optimistic for live news.

Part C. Evaluation

Evaluation and Iteration

Part B showed one evaluator-optimizer loop. This part measures the agent against alternatives, all scored with the same rubric and the same findings so the comparison is fair.

The numeric spot-check (unsupported_*) counts figures in a brief that appear in no finding. A figure the writer labels as calculated (for example "a calculated ~65% increase") is exempt: the evaluator asks for that label, and such figures are arithmetic on the findings rather than claims needing their own source. The baseline never sees the findings, so its evidence and accuracy scores are structurally low; the comparison measures whether tools and the loop produce a grounded brief.

C2. Limitations

  • Figures come from free data sources (yfinance is unofficial; NewsAPI caps at 100 articles) and are cached, so a run reflects the cache date.
  • The evaluator is an LLM and its scores vary by about 0.2 between runs.
  • The agent has no view of future events, and the brief is analysis only, not investment advice.

Reading the table.

  • Classifier. Accuracy and neutral recall improved. The gain combines the guideline-based sentiment definition with the stricter cleaning, which changed the test sample slightly.
  • NVDA news sentiment moved from net positive to net neutral. Two changes act together here: the new sentiment definition, and NewsAPI results requested by relevance, which now cover four weeks instead of the latest hours. This run cannot separate the two.
  • Agent scores moved by at most 0.2, within the evaluator's run-to-run variation, so the NLP changes alter the findings without measurably changing how briefs are judged. Changes to the evaluator can therefore be assessed on top of this run.
  • Unsupported figures rose for NVDA and XOM. The check is an exact string match. In the B8 brief, the figures it would flag that can be traced are rounded or re-unitized versions of figures in the findings ($215.9B for $215.94B; $150B for a "$150 billion" buyback) or unlabeled calculations (CPI up 3.72% year over year, computed from the FRED index levels). A figure-by-figure check of the C1 briefs is still needed before reading the rise as a quality change.
  • Speed. Specialist wall time fell by about two thirds with a similar number of headlines (99 against 100), consistent with the classify and extract batches now running concurrently.

Summary

  • Baseline vs agent. The single-prompt baseline has no tools, so its figures cannot be checked against findings; the agent's can, and the unsupported_* columns above count figures that appear in no finding.
  • Evaluator-optimizer. Every draft gets at least one revision; the B7 critiques and the B8 report show what changed.
  • Memory. The score is similar with memory on and off; the benefit shows in the plan (extra filing searches and news cross-checks that answer the previous run's lessons), not in the rubric average.
  • Robustness. Each tool call is wrapped so a failed API degrades the brief instead of ending the run, and a model that keeps returning truncated JSON is retried on the other provider.
  • Speed. The three specialists run in parallel; the timing table shows their summed time (specialist) against their wall time (specialists).
  • Known limits. The reflection step inherits the model's priors and has flagged correct current data (a 10-year yield above 5%, an analyst target well above the price) as suspicious; segment-level revenue and peer comparables are the data gaps it raises on every run.
